# Lampa Browser

Плагин для [Lampa](https://github.com/yumata/lampa): добавляет в меню пункт **«Браузер»**, где можно добавлять любые сайты прямо с ТВ и открывать их на весь экран.

## Установка

1. Выложите `lampa-browser.js` по любому адресу, доступному с ТВ: GitHub Pages, jsDelivr (`https://cdn.jsdelivr.net/gh/<user>/<repo>/lampa-browser.js`) или локальный сервер в домашней сети:
   ```sh
   python3 -m http.server 8080   # затем http://<IP-компьютера>:8080/lampa-browser.js
   ```
2. В Lampa: **Настройки → Расширения → Добавить плагин** и введите URL.
3. Перезапустите Lampa, и в боковом меню появится пункт «Браузер».

## Использование

| Действие | Как |
|---|---|
| Добавить сайт | Карточка **«+ Добавить сайт»** → ввести адрес (можно без `https://`) → название |
| Открыть | **OK** на карточке |
| Управлять сайтом пультом | После открытия ещё раз нажать **OK**: фокус переходит на страницу |
| Закрыть | **Назад** |
| Меню сайта | **Долгое нажатие OK**: внешний браузер, способ открытия по умолчанию, масштаб, переименование, смена адреса, порядок, удаление |

| Белый экран | **▼** в открытом сайте: он откроется через прокси и будет открываться так всегда |

Список сайтов хранится в `Lampa.Storage` (ключ `lampa_browser_sites`).

## Прокси для сайтов, которые запрещают встраивание

Многие сайты (например, justplayweb.com) отдают `X-Frame-Options` или CSP `frame-ancestors`, и внутри Lampa видна белая страница. Если внешнего браузера нет (Apple TV), такие сайты можно открывать через свой прокси на Cloudflare Workers (`proxy/worker.js`). Он бесплатный и не требует включённого компьютера. Прокси убирает запрещающие заголовки и переписывает ссылки сайта на свой адрес. Доступ к нему есть только по секретному токену.

Развернуть:

```sh
cd proxy
npx wrangler login              # вход в аккаунт Cloudflare (создаётся бесплатно)
npx wrangler secret put TOKEN   # придумайте токен: от 8 символов, буквы/цифры/_/-
npx wrangler deploy             # выдаст адрес https://lampa-proxy.<имя>.workers.dev
```

Затем в Lampa: «Браузер» → карточка **«Прокси»** → введите `https://lampa-proxy.<имя>.workers.dev/<TOKEN>`.

### Управление пультом на сайтах через прокси

Сайты, открытые через прокси, управляются пультом через Lampa, поэтому это работает и на Apple TV, где страница сама не получает нажатий:

| Режим | Стрелки | OK |
|---|---|---|
| **Мышь** (по умолчанию) | двигают курсор (удержание ускоряет), у края экрана прокручивают страницу | клик; клик по полю ввода открывает клавиатуру Lampa |
| **Клавиатура** (для игр) | нажимают стрелки в игре | Enter или пробел (настраивается) |

**Назад** открывает меню: закрыть сайт, переключить режим, назначить кнопку OK, обновить страницу. Режим запоминается для каждого сайта. В играх сначала кликните мышью по окну игры: нажатия клавиш уходят туда, где был последний клик.

Геймпад работает только там, где встроенный браузер поддерживает Gamepad API. В приложении Lampa для Apple TV его нет (это видно на экране «Геймпад» → «Проверка»).

Ограничения прокси:
- через прокси открываются только адреса `https://`;
- сайты со сложной защитой (Google, YouTube, банки) через прокси работать не будут;
- не входите через прокси в важные аккаунты: пароли и cookies проходят через ваш Worker;
- на Apple TV (Safari/WebKit) cookies во встроенных сайтах могут не сохраняться, поэтому вход в аккаунты может не держаться, но игры и обычные сайты работают.

## Ограничения
- **Фокус внутри сайта.** Когда фокус передан странице (второе нажатие OK), кнопки пульта получает сайт, а не Lampa. На Android кнопка «Назад» обычно всё равно работает. На некоторых Tizen/webOS она может перестать закрывать сайт, тогда выйти можно кнопкой Home или указкой Magic Remote. Если не нажимать OK второй раз, Lampa сохраняет управление, а курсор Magic Remote всё равно кликает по сайту.
- **Внешний браузер** запускается так: Tizen через `org.tizen.browser`, webOS через `com.webos.app.browser`, на остальных платформах через `window.open`.
